# Chess Wrapped — Brand Guidelines

## Brand Personality

Chess Wrapped should feel like a product made with care.

It is playful, but never childish.

It is beautiful, but never luxurious.

It is modern, but never cold.

The overall personality is:

* Cozy
* Cute
* Calm
* Friendly
* Premium
* Memorable

Imagine a beautifully designed indie app rather than a large enterprise product.

---

# Brand Promise

Chess Wrapped transforms chess statistics into a memory worth sharing.

Players shouldn't remember the numbers.

They should remember how the experience made them feel.

---

# Visual Identity

The visual language should immediately feel different from traditional chess websites.

Avoid classic chess aesthetics.

Do NOT use:

* dark wood textures
* black & gold themes
* medieval decorations
* realistic chess pieces
* tournament styling

Instead, embrace a modern and approachable identity.

## Celebration Accent

Gold

`#F5D98B`

Gold is the celebration accent.

It is not part of the everyday interface.

It appears only in moments of delight:

* the sparkle burst when a number lands
* the highlighted favorite mode
* the hero number and sparkles on the poster

Used sparingly, gold signals "this is special."

Used everywhere, it would cheapen the look — so keep it rare.

---

# Color Usage

Lavender represents the brand.

It should be used for:

* buttons
* highlights
* selected items
* important statistics
* active elements

Mint is used only as a secondary accent.

Gold is used only for celebration moments (see above).

Cream should be the primary page background.

Avoid strong saturated colors.

The interface should always feel soft.

---

# Typography

Typography should be clean and friendly.

Prefer:

* rounded feeling
* generous spacing
* medium font weights

Avoid:

* condensed fonts
* decorative fonts
* serif fonts
* heavy bold everywhere

Typography should create hierarchy through spacing rather than size alone.

---

# Spacing

Whitespace is part of the design.

Never try to fill empty areas.

A calm interface feels more premium.

Prefer:

* large padding
* generous margins
* breathing room

Over:

* compact layouts
* dense information

---

# Cards

Cards are the primary UI element.

Cards should feel soft.

Use:

* 32px border radius
* soft shadow
* subtle gradient
* large padding

Cards should never feel heavy.

Avoid thick borders.

---

# Icons

Icons should be minimal.

Rounded.

Friendly.

Simple.

Never overly detailed.

---

# Chess Pieces

Custom chess pieces are one of the unique visual elements of Chess Wrapped.

Guidelines:

* white pieces
* rounded shapes
* minimal details
* subtle lavender shadows
* no black outlines
* consistent proportions

The pieces should feel cute without becoming cartoon characters.

---

# Decorative Elements

Decorations exist only to support the atmosphere.

Examples:

* tiny sparkles
* tiny stars
* faint chess silhouettes
* blurred circles
* soft gradients

Everything should remain subtle.

Users should notice decorations only after looking carefully.

---

# Backgrounds

Avoid flat colors whenever possible.

Prefer:

* soft gradients
* gentle lighting
* subtle texture
* very faint chessboard pattern (2–3% opacity)

Backgrounds should create atmosphere without distracting from content.

---

# Buttons

Buttons should feel soft and inviting.

Rounded.

Easy to press.

Hover:

* slightly brighter
* slightly elevated

Click:

* subtle scale down
* immediately recover

Buttons should never bounce dramatically.

---

# Inputs

Inputs should feel clean and approachable.

Rounded.

Comfortable padding.

Focus state:

* lavender outline
* soft glow

Avoid harsh borders.

---

# Shadows

Use shadows sparingly.

Prefer:

* large blur
* low opacity

Avoid:

* dark shadows
* sharp shadows

Shadows should create depth, not contrast.

---

# Illustrations

Illustrations should feel:

* soft
* minimal
* rounded
* timeless

Avoid excessive detail.

Every illustration should still look good at small sizes.

---

# Tone

The interface should never feel loud.

Instead, it should quietly invite users to continue.

When choosing between:

Beautiful vs Busy

always choose Beautiful.

Simple vs Feature-rich

always choose Simple.

Cute vs Funny

always choose Cute.

Calm vs Exciting

always choose Calm.

---

# Inspiration

The feeling should be inspired by:

* Spotify Wrapped
* GitHub Year in Review
* Linear
* Raycast
* Arc Browser
* Apple

The visual language should NOT resemble:

* admin dashboards
* gaming interfaces
* crypto dashboards
* analytics platforms

---

# Brand Test

Before shipping a screen, ask these questions:

* Does this feel warm?
* Does this feel calm?
* Does this feel memorable?
* Would someone enjoy taking a screenshot?
* Does it still feel like Chess Wrapped?

If the answer to any question is "No",

simplify the design until it becomes "Yes."
